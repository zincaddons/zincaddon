# Zinc Addon Modules

Zinc Addon includes a focused set of modules for discovery, utilities, rendering, and DonutSMP-oriented gameplay.

> Module availability and behavior can vary by game version and server rules. Use responsibly and respect each server's policies.

## ESP & Detection

| Module | Purpose |
| --- | --- |
| 1x1 Hole Finder | Detects nearby 1x1 trap holes. |
| Better Storage ESP | Highlights chests, barrels, shulkers, and trapped containers. |
| Block Finder V2 | Searches loaded chunks for selected block types. |
| Chunk Finder | Detects loaded and recently visited chunks. |
| ClusterFinder | Identifies placed-block clusters that may indicate structures. |
| Dripstone Hole ESP | Highlights dripstone-covered holes. |
| HoleTunnelESP | Reveals underground tunnels and passages. |
| LightESP | Visualises light levels. |
| ShulkerHole ESP | Detects shulkers in hidden holes or walls. |
| Villager ESP | Tracks villagers and trading halls. |
| Wandering ESP | Highlights wandering traders in range. |
| Pillager ESP | Tracks pillager guards and patrol paths. |
| Beehive ESP | Locates beehives and bee nests. |
| Drowned Trident ESP | Highlights drowned mobs carrying tridents. |
| SkeletonHorse ESP | Detects skeleton horse spawns. |
