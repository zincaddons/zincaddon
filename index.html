Quick start

Install Zinc Addon

  1. Install Minecraft 1.21.11 and a compatible Fabric Loader.
  2. Download zinc-addon-fabric-1.21.11.jar.
  3. Move it to your Minecraft mods folder.
  4. Start Minecraft with your Fabric profile.
